description: The accepted final-outcome vocabulary for RPL Companion.

Use exactly three final RPL outcomes: **RPL Granted**, **In Progress**, and **RPL Not Granted**. Do not add a partial-RPL outcome.

**Why:** The user explicitly confirmed that partial RPL is not a valid outcome in this workflow.

**How to apply:** Keep outcome controls, saved-record migrations, report exports, and any future status summaries aligned to these three choices.
